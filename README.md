# 🚀 TubeShield — Distraction-Free YouTube Experience

TubeShield is a Chrome Extension designed to make YouTube cleaner, faster, and more intentional by reducing distractions and improving the viewing experience.

---

## ✨ Features

- ❌ **Hide Shorts**  
  Completely removes Shorts from the interface to eliminate endless scrolling.

- 🚫 **Block Shorts Access**  
  Prevents navigation to Shorts, helping you stay focused on meaningful content.

- ⚡ **Smart Promo Handling**  
  Minimizes interruptions during video playback for a smoother experience.

---

## 🎯 Why TubeShield?

Most of the time, it's not about discipline — it's about environment.

TubeShield helps you:
- Avoid mindless scrolling
- Stay focused by reducing ads
- Improve your overall YouTube experience

## 🛠️ Tech Stack

- TypeScript  
- Chrome Extension APIs  
- Chrome Storage API  
- DOM Manipulation (Real-time UI control)

---

## ⚡ Challenges & Learnings

- Handling YouTube’s dynamic and frequently changing DOM  
- Managing ad states without breaking playback flow  
- Persisting user state efficiently using Chrome Storage  
- Optimizing performance while modifying live UI  

This project helped me understand how large-scale platforms behave and how to build responsive systems on top of them.

## 📥 Installation (Manual Setup)

1. open repository -> https://github.com/Anubhavgrawal/TubeShield-/releases/tag/v1.0.0
 
2. Extract the project folder (if downloaded as ZIP)
 
3. Open Chrome and navigate to:
   chrome://extensions/
   
4. Enable **Developer Mode** (top right)

5. Click **Load unpacked**

6. Select the **dist** folder inside the project directory

The extension will now be installed and ready to use 🚀
